As a user, I want to be able to reset my password so that I can regain access to my account if I forget my credentials.

## Acceptance Criteria

1. User clicks "Forgot Password" link on the login page
2. System displays a form asking for the registered email address
3. User enters their email and clicks "Send Reset Link"
4. System sends a password reset email with a unique, time-limited token
5. User clicks the link in the email and is taken to a "Set New Password" page
6. User enters a new password (must meet complexity requirements: 8+ chars, 1 uppercase, 1 number, 1 special character)
7. User confirms the new password
8. System validates passwords match and meet requirements
9. System updates the password and shows a success message
10. User can now log in with the new password

## Business Rules

- Reset token expires after 24 hours
- Only the most recent reset token is valid
- Maximum 5 reset requests per hour per email
- Password cannot be the same as the last 3 passwords
- Account is temporarily locked after 3 failed reset attempts
